# 記事の評価履歴

対象は、初期シード20261028の実験を4,085 stepで停止した時点です。

| ファイル | 内容 |
|---|---|
| `evaluations.jsonl.gz` | step 0〜4,085の全4,086時点。20体の対ランダム器・位置評価器・自分の初期モデルの成績、実測step、全個体平均 |
| `learner-history.jsonl.gz` | 各stepの学習担当者と55%超の達成有無。グラフの背景描画用 |
| `experiment-config.json` | モデル・PPO・報酬・対戦・評価の設定。保存先などローカルパスを除外 |
| `environment.json` | 元のPython・NumPy・PyTorch・描画環境とGPU名 |
| `reference-results.json` | step 4,085時点の累計対局数・経過時間・学習回数・評価値 |

`evaluated_step` は実際にその個体を評価したstepです。重みを変更していない個体について、同じ評価値を引き継いだ行も含みます。隣り合う時点や20体を独立な実験として数えることはできません。

勝率は勝ち数/全対局数です。引き分けは半勝にしていません。固定器ごとの評価は、各個体128局、先後64局ずつです。

このデータを使った描画は、リポジトリ直下で `python plot_results.py` を実行してください。学習の実行は必要ありません。
